# Пример ввода для демонстрации

`demo-input.txt` — обычная последовательность пользовательского ввода для интерактивного `Main`.
В ней нет Java-кода и она не создаёт объекты напрямую: приложение читает строки так же, как при вводе с клавиатуры.

Сценарий по порядку:

1. отчёты на пустом парке (пункты 3–6);
2. ошибки ввода: неизвестный пункт меню, неизвестный тип транспорта, не число, пустой инвентарный номер,
   простота вне диапазона 1–10, некорректное число для энергии;
3. добавление исправного самоката, самоката с низкой простотой (в список новичков не попадёт),
   неисправного самоката (отказ техосмотра), велосипеда, электровелосипеда;
4. добавление шлема, зарядной станции и зарядного шкафа;
5. попытка добавить дубликат номера (`vk-s-001` совпадает с `VK-S-001`: регистр не важен);
6. итоговые отчёты: сводка, транспорт для новичков, весь инвентарь, прокатный транспорт; выход.

Для реальной работы запускайте `run.bat` / `run.sh` и вводите данные вручную.
Для повторяемой демонстрации — `demo.bat` / `demo.sh`: они подают этот файл на стандартный ввод.
